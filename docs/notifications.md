# Push Notifications

Print, progress, error and filament notifications with camera snapshots,
sent through ntfy, Gotify, Pushover, Telegram, Discord, email or a webhook.

[pushraker](https://github.com/noon92/pushraker) is built into paxx12
extended firmware, but requires user configuration: open **Push
Notifications** from the Links list at the top of
[Firmware Config](firmware_config.md) (`http://<printer>/notifications/`).

**[Push Notifications guide](https://github.com/noon92/pushraker/blob/main/docs/guide.md)**: services, setup, self-hosting a push
server, notifications from G-code, security, the configuration file and
troubleshooting.
